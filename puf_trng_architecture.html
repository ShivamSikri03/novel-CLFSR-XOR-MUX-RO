1. Oscillator Core (Entropy Bank)

8 to 16 identical inverter chains synthesized with (* DONT_TOUCH = "TRUE" *) attributes to prevent logic minimization.

  • Static Variation: Sub-nanosecond propagation delay differences between matched pairs.
  • Dynamic Entropy: Thermal noise induces Gaussian edge jitter ($\sigma_j \approx 50-200\text{ ps}$).

2. Path A: RO-PUF Subsystem

Extracts deterministic, chip-unique fingerprint for cryptographic device identity and root-of-trust keying.

  • Challenge MUX: Selects RO pairs $(RO_A, RO_B)$ to evaluate.
  • 16-bit Ripple Counters: Measures oscillation cycles across window $T_{meas} = 2^{16}$.
  • Fuzzy Extractor: Corrects rare thermal bit flips (Intra-HD $< 1\%$) using BCH codes.

3. Path B: RO-TRNG Subsystem

Generates high-speed, unpredictable bitstreams compliant with NIST SP 800-22 and SP 800-90B.

  • Multi-RO XOR Tree: Superimposes independent phase slips into high-frequency transitions.
  • Dual-Rank Sampler: Resolves metastability when sampled with reference clock.
  • Von Neumann Debiasing: Enforces perfect 50% 1s/0s probability balance.

4. Hybrid CLFSR Conditioner

Fuses the PUF fingerprint and TRNG dynamic entropy into an unbreakable stream.

  • PUF-Seeded: State trajectory is unique per physical silicon chip.
  • Jitter-Perturbed MUX: Real-time jitter dynamically switches Galois polynomial feedback taps.
  • Cryptographic Quality: Passes all 15 NIST SP 800-22 statistical batteries.

Physics & Operating Principles

Mathematical foundation of static process variations versus dynamic thermal jitter.

Static Process Variations (PUF Foundation)

Sub-micron manufacturing non-uniformities create spatial variations in threshold voltages and gate delays:

f_{RO} = \frac{1}{2 \cdot N \cdot (t_{pd0} + \Delta t_{process})}

Over a long measurement time ($T_{meas} = 2^{16}$ clock cycles), static differences dwarf thermal noise, giving a deterministic bit:

PUF\_BIT = \begin{cases} 1 & \text{if } Cnt_A > Cnt_B \\ 0 & \text{if } Cnt_A \le Cnt_B \end{cases}

Dynamic Thermal Jitter (TRNG Foundation)

Microscopic thermal electron agitation inside transistor channels induces cycle-to-cycle phase jitter:

\sigma_{jitter}^2 \propto \frac{k_B \cdot T}{I_{bias} \cdot (V_{DD} - V_{th})} \cdot N_{stages}

Sampling the XOR superposition of multiple oscillating rings produces true Shannon entropy:

H_{\infty} = -\log_2(\max(p_0, p_1)) \ge 0.964\text{ bits/bit}

Synthesizable Verilog RTL Implementation

Complete Verilog code ready for FPGA synthesis in Vivado / Quartus.

puf_trng_top.v (Dual-Mode Controller) 
// ============================================================================
// Module: puf_trng_top
// Description: Unified Dual-Mode RO-PUF and Jitter-Harvesting TRNG Engine
// ============================================================================
module puf_trng_top #(
    parameter NUM_RO = 8,
    parameter MEASURE_BITS = 16
)(
    input  wire                    clk,        // Reference System Clock (50/100 MHz)
    input  wire                    rst_n,      // Active-low asynchronous reset
    input  wire                    mode_sel,   // 0 = PUF Mode, 1 = TRNG Mode
    input  wire [2:0]              puf_pair_a, // Index for RO A
    input  wire [2:0]              puf_pair_b, // Index for RO B
    input  wire                    puf_start,  // Trigger PUF measurement
    output reg                     puf_ready,  // PUF bit ready
    output reg                     puf_bit,    // Static PUF Response Bit
    output reg                     trng_valid, // TRNG valid strobe
    output reg                     trng_bit    // True Random Bitstream
);

    wire [NUM_RO-1:0] ro_out;

    // 1. Instantiate Entropy Source Bank
    genvar i;
    generate
        for (i = 0; i < NUM_RO; i = i + 1) begin : gen_ro
            ring_oscillator #(.STAGES(3)) u_ro (
                .enable (1'b1),
                .ro_out (ro_out[i])
            );
        end
    endgenerate

    // 2. PUF Path: Dual Counter Frequency Comparator
    wire ro_a = ro_out[puf_pair_a];
    wire ro_b = ro_out[puf_pair_b];

    reg [MEASURE_BITS-1:0] cnt_ref;
    reg [MEASURE_BITS-1:0] cnt_a, cnt_b;
    reg                   measuring;

    always @(posedge ro_a or negedge rst_n) begin
        if (!rst_n) cnt_a <= 0;
        else if (measuring) cnt_a <= cnt_a + 1'b1;
    end

    always @(posedge ro_b or negedge rst_n) begin
        if (!rst_n) cnt_b <= 0;
        else if (measuring) cnt_b <= cnt_b + 1'b1;
    end

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            cnt_ref   <= 0;
            measuring <= 1'b0;
            puf_ready <= 1'b0;
            puf_bit   <= 1'b0;
        end else if (mode_sel == 1'b0) begin
            if (puf_start && !measuring) begin
                measuring <= 1'b1;
                cnt_ref   <= 0;
                puf_ready <= 1'b0;
            end else if (measuring) begin
                cnt_ref <= cnt_ref + 1'b1;
                if (cnt_ref == {MEASURE_BITS{1'b1}}) begin
                    measuring <= 1'b0;
                    puf_ready <= 1'b1;
                    puf_bit   <= (cnt_a > cnt_b) ? 1'b1 : 1'b0;
                end
            end
        end
    end

    // 3. TRNG Path: Multi-RO XOR Tree + Von Neumann Filter
    wire xor_entropy = ^ro_out;
    reg  meta_1, meta_2;
    reg  [1:0] vn_pair;
    reg       vn_phase;

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            meta_1     <= 1'b0;
            meta_2     <= 1'b0;
            trng_valid <= 1'b0;
            trng_bit   <= 1'b0;
            vn_phase   <= 1'b0;
        end else if (mode_sel == 1'b1) begin
            meta_1 <= xor_entropy;
            meta_2 <= meta_1;

            if (!vn_phase) begin
                vn_pair[0] <= meta_2;
                vn_phase   <= 1'b1;
                trng_valid <= 1'b0;
            end else begin
                vn_pair[1] <= meta_2;
                vn_phase   <= 1'b0;
                if (vn_pair[0] ^ meta_2) begin
                    trng_bit   <= vn_pair[0];
                    trng_valid <= 1'b1;
                end else begin
                    trng_valid <= 1'b0;
                end
            end
        end
    end

endmodule
